# PerAnt 0.9.0 小蚁界面预览版

版本：`0.9.0+2009`。发布文档整理于 2026-11-16；以下应用验收来自 2026-11-15 的本地记录。

## 这版更新

PerAnt 从原有聊天框架迁移到 Concept 06：暖白与鼠尾草绿、小蚁角色，以及“对话 / 电脑 / 文件”三项导航。首页优先呈现对话入口，模型设置、最近会话和任务记录收进菜单。

- 对话保留真实 API 流式回复、任务进度、文档入口、取消与用户接管。快捷建议连接现有工具，不使用演示回复冒充模型结果。
- 授权改为底部弹层，展示实际服务、模型、地址、发送文字与数据范围。普通聊天可在当前运行、当前会话和相同模型配置下记住授权，并可撤销；容器协作每次单独授权。
- 电脑页读取实际运行时状态。进入电脑页不启动桌面；用户选择查看后才连接画面，隐藏时释放查看连接与图像。
- 文件页保留本机文档的创建、导入、搜索、编辑和版本确认，并明确区分本机资料与 Linux `/workspace`。
- 小蚁昵称、界面语气与震动偏好保存在本机，兼容旧快照。界面语气不修改模型 system prompt。
- 更新 Android 自适应图标、常规图标及 iOS AppIcon 资源。角色及图标来源、提示词和导出记录保留在仓库中。

截图见 [README](../../README.md#界面预览)，实现范围见 [Concept 06 说明](../UI_CONCEPT06_IMPLEMENTATION.md)。

## 验证范围

- 本地格式、静态分析、Dart 280 项和 Python 14 项通过；2 项可选离线截图跳过。
- API 36 ARM64、4 GB / 4 核 / 宿主 GPU 模拟器原生检查 3/3：真实凭据、隔离 SQLite 保存重开及 Python 文档编辑确认，云请求为 0。
- 最终 APK 在 360 × 740、390 × 844、430 × 932 三种手机尺寸核对了布局、导航、键盘返回、草稿保留、菜单/偏好弹层及系统图标。
- 3 GB / 2 核 / 软件渲染配置的 Linux 冷安装曾超时，失败保留。硬件设置同时变化，不能将后续通过归因于内存单一因素。
- 原生检查之后的表现层收尾由最终本地回归和 APK 界面遍历覆盖；本轮未重跑全部历史 Linux、浏览器与 Office 测试。

未运行 GitHub CI。模拟器结果不代表实体低配手机、系统中文输入法、长期后台、真实模型服务或 iOS 设备已通过验收。
