# UI 参考与当前边界

核对日期：2026-11-13。本轮按用户要求，以 nanoMuse 的聊天体验作为布局参考，同时保留 PerAnt 品牌和已实现功能。

文中标注的本地开发证据和构建产物（如 `artifacts/`、`.tooling/` 与生成的运行资源）未随本次源码发布；源码预览的验证范围以文内记录为准。

## 参考版本

- [nanoMuse Android 官方文档](https://nanomuse.cn/docs/zh/android)是当前手机端依据。该页说明现在的 Android App 基于原生 OpenMinis；较早的 Python 服务与 WebView 方案已归档。
- [nanoMuse 应用页](https://nanomuse.cn/docs/zh/app)明确标为旧 Python 线的设计记录。可以辅助理解其聊天、会话抽屉和导航语言，不据此给 PerAnt 引入旧服务架构或宣称当前 Android 全部行为相同。

## 布局方向

采用单色聊天底色、用户与助手有区分的胶囊消息；头部形象下显示真实工作步骤。输入框位于浮动胶囊导航上方，两者边缘对齐；官方 Android 文档给出手机横向边距 16 dp、宽屏居中且最大宽度 420 dp，并要求键盘、步骤条与末条消息互相避让。[当前 Android 外观说明](https://nanomuse.cn/docs/zh/android)

会话入口放在聊天左上侧，抽屉承担会话管理；流式回复继续在聊天内呈现。旧应用页中的五项导航属于其自身功能集合，不原样映射为 PerAnt 的业务模块。[应用布局记录](https://nanomuse.cn/docs/zh/app)

## 映射到 PerAnt

| 现有页面 | 本轮布局映射 | 必须保持的真实行为 |
| --- | --- | --- |
| 聊天 | 首要入口；PerAnt 形象与状态、会话抽屉、对比明确的消息、输入框与浮动导航 | 流式文字、停止请求、逐任务云授权；不能伪造工具完成或本地模型回复 |
| 资料 | 沿用单色表面与轻量文件列表，进入 Markdown 编辑和预览 | 只显示实际创建/导入的文档和版本；不假装已有全文或语义知识库 |
| 任务 | 与聊天共用状态语言，呈现实际任务记录与中断结果 | 不把请求中断显示为完成，不伪造长期目标、定时工作或后台进度 |
| 设置 | 相同视觉体系，承载供应商配置、连接测试和设备能力 | 尚未接入的 Linux、端侧推理和后台执行明确显示不可用 |

底部导航适配以上四个现有页面，不增加动态、点子或目标的占位功能。头像使用 PerAnt 自己的形象与名称，不复制 nanoMuse 品牌标识；形象状态来自配置和请求状态，不附加虚构的情绪或能力。

## 验证边界

当前属于依据官方文档进行的视觉与交互结构对齐，**尚未做最新 nanoMuse APK 与 PerAnt 在相同设备、字体和系统设置下的像素级 1:1 对照**。官方旧应用页的图片不能替代当前 Android 版本的基准截图。

本轮最终检查应记录手机宽度、宽窗口和键盘弹出时的实际截图，验证输入框、导航及最后一条消息可见，并重测会话、停止、文档编辑与设置操作。最终 UI 验证结果由集成检查补充，原生构建通过不等于视觉还原已经验收。
